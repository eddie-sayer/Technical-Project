# Technical-Project

This is a simple evacuation simulation, based on the social force model by Dirk Helbing and Peter Molnar.
Please do not change anything in the code before running it.
Please only play the simulation once, as this will provide the most representative results :).
When you have completed the simulation, please close the window, upon which two data files will be downloaded in the same location
as this file ('output.csv' and 'output_data_records.csv'). Please email these to gj20079@bristol.ac.uk along with your age and gender <3.

NOTE: Please ensure you have the following packages installed on your device for the simulation to run: 
-pygame
-sys
-math
-random
-csv
-pandas

NOTE: No longer at Bristol University, so this email is no longer valid!

NOTE: As the experiment is now closed, you may test any treatment combination by running the correct Python file:

Control: Evac_sim_C.py

Heterogeneous: Evac_sim_H.py
Assymetric and Heterogeneous: Evac_sim_HA.py

Please feel free to have a look through the code, everything is labelled for coherence.
The Results folder contains the data collected on the 40 participants during the trial period. No sensitive information is publicly available. There are various other files used to generate graphs on the data collected in this folder, they may not be functional.
player_paths_all_trials.py and player_paths_heatmaps.py contain code that generated visualisations of results from the experiment, they may not be functional.
gradual_build.py was my working file before creating seperate versions for each treatment to be sent to participants.
